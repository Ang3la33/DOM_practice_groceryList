# 🛒 Grocery List – DOM Practice Project

This mini project was built to practice and reinforce DOM manipulation and event handling in vanilla JavaScript.

---

## ✨ Features

- Add grocery items to a list
- Mark items as complete
- Remove items dynamically
- Clean, minimal UI

---

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- DOM API
- Event listeners

---

## 🚀 How to Run

Just open `index.html` in your browser.

---

## 🧠 Notes

This project was created to strengthen my understanding of core JavaScript concepts, especially how to manipulate the DOM and handle events without using frameworks.
