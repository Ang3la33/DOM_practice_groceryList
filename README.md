# 🛒 DOM Grocery List App

A fun, interactive grocery list app built with **HTML, CSS, and JavaScript** to practice DOM manipulation! Users can add categorized grocery items, filter by category, and visually organize their list — all with a sleek custom UI and responsive design.

---

## ✨ Features

- 🧠 **Pure JavaScript DOM manipulation**
- 🗂️ Add grocery items by category (Dairy, Meat & Poultry, Fruits & Vegetables, etc.)
- 🛒 Styled “Add Item” buttons with shopping cart icons
- 🎯 Real-time item filtering by category using a dropdown
- 🎨 Custom color palette, centered layout, and interactive UI
- 💡 Designed for practicing frontend fundamentals with modern styling

---

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- DOM API
- Event listeners

---

## 🚀 How to Run

Just open `index.html` in your browser.

---

This project was created to strengthen my understanding of core JavaScript concepts, especially how to manipulate the DOM and handle events without using frameworks.
